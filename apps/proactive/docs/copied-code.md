# Code copied in this app

This app keeps code that another place also has. Each copy is listed here with its source and what changed, so that a fix in one copy goes into each copy, and the commit names all of them.

| Copy                                                                                     | Source                                                            | What changed                                                                                                                                                                                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The `codex exec` run in `write` of `src/rules/planning-meetings/meeting-brief-writer.ts` | The `codex exec` run in `act` of `src/engine/agent-automation.ts` | The sandbox is `read-only`, not `workspace-write`. `--cd` is the scratch folder, not the target folder. The scratch folder is in the target folder, not in `os.tmpdir()`, because the brief is renamed into place and a rename across two disks fails with `EXDEV`. The result is the path of the renamed brief, not the text of the last message. |

Both runs give Codex the same contract: `exec --ephemeral --ignore-user-config --skip-git-repo-check --cd <folder> --output-last-message <file> -`, the prompt on stdin, a limit of 180 s and 8 MiB, and an empty last message is a failure. This project counts places, not packages, so the two runs stay copies until a third place runs Codex. Then the run moves into one class, and both copies go. Until then, a fix of the run goes into both places, and the commit names both (backlog #4495).
